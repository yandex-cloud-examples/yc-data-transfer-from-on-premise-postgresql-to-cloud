# Migrating a PostgreSQL cluster through Yandex Data Transfer

With [Data Transfer](https://yandex.cloud/docs/data-transfer), you can transfer a PostgreSQL database to [Yandex Managed Service for PostgreSQL](https://yandex.cloud/docs/managed-postgresql). See [this tutorial](https://yandex.cloud/docs/data-transfer/tutorials/managed-postgresql) to learn how to set up the solution with Terraform. This repository contains the configuration file you will need: [data-transfer-pgsql-mpg.tf](data-transfer-pgsql-mpg.tf).
